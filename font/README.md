# 네마음체 (Nemaum) — 가변 한글 폰트

가독성을 높인 한글 폰트입니다. 굵기(얇은·기본·볼드)와 글자 크기별 모양(본문용·제목용)을
**가변 폰트 한 파일**로 조절할 수 있고, 아이폰 iFont 등에서 쓸 수 있는 정적 파일도 함께 만듭니다.
(이름은 임시입니다. `src/config.py`의 `FAMILY`, `FAMILY_KO`에서 바꿉니다.)

## 이 폰트는 새로 그린 폰트입니다

리틱체(REATIC)의 라이선스는 수정·가공·재배포를 금지하므로, 이 폰트는 리틱체를 변형하지 않았습니다.
글자 윤곽은 `src/`의 코드가 직접 만들어 내는 **자체 설계**입니다. 리틱체 파일은 이 저장소에 포함하지 않습니다.

## 만들어지는 파일 (`font/dist/`)

| 폴더 | 내용 |
|---|---|
| `variable/Nemaum-VF.ttf`, `.woff2` | 가변 폰트. 굵기 `wght` 100–900, 크기별 모양 `opsz` 12–72 |
| `text/{ttf,otf,woff2,woff}/` | 본문용(작은 글씨에 맞춘 모양) Light / Regular / Bold |
| `display/{ttf,otf,woff2,woff}/` | 제목용(큰 글씨에 맞춘 모양) Light / Regular / Bold |

## 지원하는 글자

- 한글 완성형 11,172자, 한글 호환 자모, 현대 한글 자모(U+1100–11FF 일부)
- 영문, 숫자, ASCII 기호, 전각 영문·기호(FF01–FF5E)
- 라틴 악센트 문자(À É Ñ Ç 등), 그리스·키릴 문자
- 이모티콘용 기호: 표 그리기 선(U+2500–257F), 블록(▀▄█░▒▓), 점자(⠿⣿), 도형(○●◎◕◠◡ 등),
  화살표, 하트·별·꽃·음표, `ʕ ʔ ᴥ ᴗ ᵔ ‿ ︵ ﹏ ಠ ಥ ٩ ۶ ヮ ツ ･ﾟ ｡` 등 자주 쓰는 이모티콘 문자
- 결합 문자(U+0300–036F 일부), 공백·0폭 문자·한글 채움 문자(U+3164), 변이 선택자
- 동그라미·괄호 숫자와 자모(①, ㉠, ㉮, ㈜), 로마 숫자, 분수, 윗첨자·아랫첨자, 단위(㎏ ㎡ ℃)

폰트에 없는 글자는 기기의 기본 글꼴로 자동 대체됩니다. 모든 유니코드 글자를 넣을 수는 없어서,
**지원하지 않는 글자는 아이폰·안드로이드·웹 모두 시스템 글꼴로 표시**됩니다.

## 쓰는 방법

### 웹 (CSS)

```css
@font-face {
  font-family: "Nemaum VF";
  src: url("dist/variable/Nemaum-VF.woff2") format("woff2");
  font-weight: 100 900;
  font-display: swap;
}
body { font-family: "Nemaum VF", system-ui, sans-serif; font-optical-sizing: auto; }
h1   { font-weight: 800; }                      /* 굵기 */
.big { font-variation-settings: "opsz" 72; }    /* 제목용 모양 */
```

### 아이폰 (iFont 앱)

1. `dist/text/ttf/Nemaum-Regular.ttf`(또는 `.otf`)를 아이폰으로 옮깁니다 (AirDrop, 파일 앱 등).
2. iFont 앱에서 파일을 열어 설치하고, 설정에서 프로필을 허용합니다.
3. iFont는 보통 가변 폰트를 지원하지 않으므로 **정적 파일(`text/`, `display/`)** 을 쓰세요.
4. 카카오톡은 기기 글꼴이 아니라 앱 자체 글꼴을 쓰는 경우가 있어서, 설치한 폰트가 대화창에 적용되는지는
   **기기에서 직접 확인해야 합니다.** (이 저장소에서는 검증하지 못했습니다.)

## 직접 빌드하기

```bash
pip install fonttools brotli skia-pathops
python3 font/build.py            # 전체 (몇 분 걸립니다)
python3 font/build.py --sample   # 한글 40자당 1자만 넣은 빠른 시험 빌드
```

구조

- `src/hangul.py` — 자모 뼈대와 음절 배치 (초성·중성·종성)
- `src/latin.py` — 영문·숫자·기호
- `src/symbols_a.py` — 표 그리기 선, 블록, 점자, 도형, 화살표, 하트·별
- `src/symbols_b.py` — 그리스·키릴, CJK 문장부호, 가나, 이모티콘 문자, 수학 기호
- `src/compose.py` — 악센트·전각·동그라미·첨자처럼 다른 글리프를 조합해서 만드는 글자
- `src/geom.py` — 중심선을 겹치는 사각형으로 바꾸는 기하 코드 (굵기가 달라도 점 개수가 같아 가변 폰트가 됩니다)
- `build.py` — 마스터 5개를 만들고 `fontTools.varLib`로 가변 폰트를 합친 뒤 정적 파일을 뽑습니다

## 알려진 한계 (v0.1)

- 획 끝이 직각인 단순한 기하 서체입니다. 디자이너의 다듬기가 필요합니다.
- 볼드에서 겹받침(예: 곬, 읊) 글자는 아직 획이 붙어 보입니다.
- 결합 문자는 앞 글자 폭을 모르므로 위치가 대략적입니다 (GPOS 미지원).
- 옛 한글 조합(U+1100 계열 낱자 연속)은 완성형으로 합쳐지지 않습니다 (GSUB 미지원).
- 힌팅이 없습니다. 아주 작은 크기(10px 미만)에서는 렌더러에 따라 흐릿할 수 있습니다.
