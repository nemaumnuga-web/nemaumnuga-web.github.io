# 보관본: 정사각 격자 버전 (grid-v1)

리틱체식 정사각 프레임으로 만든 버전입니다. 리틱체와 지나치게 비슷하다는 측정 결과
(한글 겹침도 0.58~0.71)가 나와서, 이후 버전에서 짜임을 바꿨습니다. 비교용으로 보관합니다.

- 소스 커밋: `7631a85` (`git checkout 7631a85 -- font/src font/build.py` 로 되돌릴 수 있습니다)
- `nemaum/`: Light / Regular / Bold TTF, 가변 폰트 WOFF2
- `nemaum-round/`: 둥근 판 Light / Regular / Bold TTF, 가변 폰트 WOFF2
