# 네마음체 마케팅 계획서 (초안)

## Context

리틱체(REATIC)를 바탕으로 가독성을 높이고, 볼드·기본·얇은 굵기와 글자 크기별 변형을 나누고, 신기술(가변 폰트 등)을 넣은 새 글씨체를 출시하려는 계획입니다. 출시 전에 제품 방향과 마케팅 계획을 먼저 정리합니다.

**중요한 제약: 리틱체 라이선스 (LICENSE.txt)**
- "임의 수정, 가공, 무단 재배포"가 금지되어 있습니다.
- 따라서 리틱체를 직접 변형해 가독성을 올리거나 굵기를 나누는 작업은 제작사(리틱인더스트리)의 사전 허락 없이는 할 수 없습니다.
- 이 계획은 두 경로 중 하나를 전제로 합니다.
  - **A안(권장)**: 리틱체의 분위기만 참고해 글자 윤곽을 새로 그린 오리지널 폰트를 제작합니다. 기존 글자 외곽선을 복사하지 않습니다.
  - **B안**: 리틱인더스트리에 2차 제작(수정·파생) 허락을 받은 뒤 리틱체를 기반으로 제작합니다.

## 1. 제품 정의

| 항목 | 내용 |
|---|---|
| 제품명 | 미정 (예: 가칭 "OO체") |
| 형태 | 가변 폰트 1파일 (굵기·폭·광학 크기 축 조절) + 정적 파일 (Thin / Regular / Bold) |
| 굵기 구분 | 얇은(Light/Thin), 기본(Regular), 볼드(Bold) |
| 크기 구분 | 광학 크기(opsz) 축: 작은 본문용 / 중간 / 큰 제목용 글자 모양을 자동 조절 |
| 가독성 목표 | 작은 크기에서 x-height 확대, 획 간격·자간 최적화, 자음·모음 구분 명확화 |
| 글자 범위 | 완성형 한글 11,172자 + 영문·숫자·기호 (처음부터 전체 제작, 결정됨) |

## 2. 타깃 고객

1. **디자이너·콘텐츠 제작자**: 썸네일, 카드뉴스, 유튜브 자막 (가독성과 굵기 선택 중요)
2. **소상공인·개인 브랜딩**: 간판, 메뉴판, 상세페이지 (무료 또는 저렴한 상업 라이선스 필요)
3. **웹 개발자·기획자**: 웹사이트 본문·제목용 (파일 용량, WOFF2, 웹 최적화 중요)

우선순위 제안: 1번(콘텐츠 제작자)을 첫 타깃으로 잡고, 샘플 이미지와 튜토리얼로 입소문을 만듭니다.

## 3. 차별점 (포지셔닝)

- **가독성**: 작은 크기에서도 읽히는 한글 설계 (실제 가독성 테스트 결과를 공개)
- **하나의 파일, 여러 굵기와 크기**: 가변 폰트로 용량을 줄이고 설정 자유도를 높임
- **웹 최적화**: WOFF2 + 한글 서브셋 분할 로딩 (`unicode-range`) 지원
- **명확한 라이선스**: 개인 무료 / 상업용 / 웹용을 나눠 표로 제시

## 4. 신기술 후보 (기술 검토 필요)

| 기술 | 효과 | 난이도 |
|---|---|---|
| 가변 폰트 (wght, wdth, opsz 축) | 파일 1개로 굵기·폭·크기 대응 | 높음 |
| 광학 크기 자동 전환 | 작은 글자와 큰 글자의 모양을 따로 최적화 | 높음 |
| WOFF2 + 한글 서브셋 분할 | 웹에서 필요한 글자만 로딩, 용량 절감 | 중간 |
| OpenType 대체 글자 (ss01 등) | 개성 있는 대체 글자 세트 제공 | 중간 |
| 컬러 폰트 (COLR/CPAL) | 이모지형·2색 타이틀 등 | 낮음~중간 (후순위) |

## 5. 가격·배포 (초안)

- **개인용 무료**: 개인 블로그, 학습, 비영리 용도
- **상업용 유료**: 인쇄물·영상·제품 판매 등
- **웹 라이선스**: 웹사이트 임베드 허용 (별도 가격)
- 배포 채널: 자체 다운로드 페이지(GitHub Pages 등), 디자인 커뮤니티, 폰트 마켓

## 6. 마케팅 채널과 실행

| 단계 | 채널 | 내용 |
|---|---|---|
| 사전 | 인스타그램·유튜브 | 가독성 비교 영상 ("작은 글씨 테스트"), 기존 폰트와 나란히 비교 |
| 사전 | 블로그·검색 | "무료 한글 폰트 추천", "카드뉴스 글씨체" 등 검색 키워드 글 |
| 출시 | 디자인 커뮤니티 | 샘플 시안 공개, 피드백 수집 |
| 출시 | 튜토리얼 | 굵기 변형과 가변 폰트 사용법 영상·가이드 |
| 출시 후 | 사례 공유 | 사용자 작품 모음, 후기 이벤트 |

## 7. 일정 (예상)

| 기간 | 작업 |
|---|---|
| 1~2주 | 라이선스 확인, 경쟁 폰트 조사, 제품 정의 확정 |
| 3~8주 | 완성형 11,172자 제작 (자주 쓰는 글자부터 순서대로), 굵기·크기 변형 설계 |
| 9~10주 | 가독성 테스트, 웹·문서 환경 테스트 |
| 11~12주 | 다운로드 페이지, 라이선스 문서, 출시 |
| 출시 후 | 개선 버전, 사용자 피드백 반영 |

## 8. 성과 지표 (KPI)

- 다운로드 수 (월간)
- 다운로드 → 상업용 라이선스 전환율
- 샘플 콘텐츠 조회·공유 수
- 재방문 및 사용자 후기 수

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 리틱체 무단 수정으로 저작권 문제 | A안(오리지널 제작) 또는 제작사 허락 확보 |
| 기존 폰트와 외형이 너무 비슷하다는 평가 | 자체 글자 설계, 외곽선 복사 금지 |
| 완성형 11,172자 제작 비용·시간 | 자주 쓰는 글자부터 순서대로 제작하고, 일정을 단계별로 점검 |
| 웹 용량 증가 | 가변 폰트, WOFF2, 서브셋 분할 |
| 예산·인력 부족 | 1단계 범위 축소, 외주 검토 |

## 10. 검증 방법 (계획 단계)

- 이 계획서를 검토받아 제품 정의와 우선순위 확정
- 라이선스 문의 결과에 따라 A안/B안 결정
- 출시 전: 작은 크기(10~12px) 가독성 테스트, 굵기별 렌더링 확인, 웹 로딩 속도 측정, 폰트 검증 도구(OTS, fontTools)로 파일 점검

## 파일 형식과 사용 환경 (추가 요청)

- **모든 형식 제작**: TTF, OTF, WOFF, WOFF2 (웹용), 가변 폰트 파일, 정적 굵기별 파일(얇은/기본/볼드)
- **아이폰 사용**: iFont 앱에 설치해 쓸 수 있도록 TTF/OTF 파일을 제공하고, 설치 방법 안내를 포함합니다.
- **카카오톡 사용**: 카카오톡이 사용자 설치 폰트를 쓰는지 확인이 필요합니다. 확인되지 않으면 "카카오톡에서 쓰는 방법" 안내에 한계를 명시합니다.
- 검증: 아이폰 실기기 또는 시뮬레이터에서 iFont 설치와 카카오톡 표시 여부를 테스트합니다.

## 결정 사항

1. 제작 방식: **A안 (오리지널 제작)**. 리틱체는 참고만 하고 글자 외곽선은 새로 그립니다.
2. 글자 범위: **완성형 11,172자 전체**를 처음부터 제작합니다.
3. 가격 모델: **무료 + 유료 혼합** (개인용 무료, 상업·웹용 유료)
