# 라온 피코 실험: 작은 한국어 채팅 모델 직접 학습

Gemma 3 270M(instruct)을 KoAlpaca v1.1a 한국어 질문·답변(약 2만 1천 개)으로 CPU에서 파인튜닝한 실험이에요.

## 설정

- 바탕 모델: `unsloth/gemma-3-270m-it` (파라미터 2억 6,800만 개, 라온 나노의 약 1/10)
- 학습: 600단계 × 배치 8 (데이터의 약 23%), 학습률 5e-5, 최대 320토큰
- 단어 사전(임베딩)은 얼리고 트랜스포머 층 1억 개만 학습
- 답변 부분만 채점하고, 26만 단어 출력은 512개씩 나눠 계산해서 메모리 15GB 안에 맞춤
- CPU 4코어, 약 108분, 100단계마다 체크포인트 저장

## 결과

| | 채점용 200문항 오차 | 혼란도(perplexity) |
|---|---|---|
| 학습 전 | 3.61 | 37.0 |
| 200단계 | 2.80 | 16.4 |
| 400단계 | 2.66 | 14.4 |
| 600단계 | **2.62** | **13.7** |

생성 속도(PyTorch fp32, CPU 4코어)는 학습 전후 모두 약 27토큰/초예요. 같은 컨테이너 기준 라온 나노(약 14토큰/초)의 약 2배예요. 단, 측정 도구가 달라서(llama.cpp와 PyTorch) 정확한 비교는 아니에요.

답변 예시는 [RESULTS_samples.md](RESULTS_samples.md)에 있어요.

## 판단

- **좋아진 점:** 한국어 문장이 길고 자연스러워졌어요. 학습 전처럼 질문에 한 줄로 끝내거나 다른 나라 말이 섞이는 일이 줄었어요.
- **한계:** 사실은 자주 틀려요. 광합성, KTX 소요 시간, 리스트와 튜플의 차이 같은 지식 질문에 그럴듯하지만 틀린 답을 해요. 270M 크기에는 지식을 담을 공간이 부족해요.
- **결론:** 지금 상태로는 라온 나노를 대신할 수 없어요. 인사·잡담처럼 사실 확인이 필요 없는 짧은 대화나, 웹 검색 결과를 요약하는 일처럼 답의 근거를 함께 주는 일에 쓸 수 있는지는 따로 실험해 봐야 해요.

## 실행

```
pip install --index-url https://download.pytorch.org/whl/cpu torch
pip install transformers datasets accelerate
python3 llm/train.py --steps 600 --out out/raon-pico   # 멈추면 같은 명령으로 이어서 학습
python3 llm/compare.py out/raon-pico > llm/RESULTS_samples.md
```

모델 파일(약 1GB)은 이 저장소에 올리지 않았어요.
