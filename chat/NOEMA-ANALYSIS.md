# Noema 분석과 채팅 v15에 옮긴 것

Noema(App Store 이름 "Noema: Local AI & Offline LLM")는 iPhone·iPad·Mac·Vision Pro에서 언어 모델을 **기기 안에서** 돌리는 무료 앱입니다. 이 문서는 공개된 자료(App Store 설명과 버전 기록, 공식 사이트, 리뷰)로 Noema를 기능별로 분석하고, 그중 무엇을 이 웹 채팅(`chat/`)에 옮겼는지, 무엇을 웹에서는 옮길 수 없는지 정리합니다.

참고 자료
- App Store: https://apps.apple.com/app/id6751169935 (설명, 버전 1.0 → 4.4 기록)
- 공식 사이트: https://noema.pages.dev/ (기능 소개, 개인정보 표)
- 리뷰: https://www.promptquorum.com/power-local-llm/noema-review

이름·아이콘·디자인은 가져오지 않았습니다. 기능의 아이디어만 이 사이트의 기존 채팅 화면과 말투에 맞춰 새로 만들었습니다.

## 1. Noema는 어떤 앱인가

한 줄로 말하면 **"내 기기에서 도는 개인 AI + 내 자료 + 공부 도구"** 입니다.

| 축 | 내용 |
|---|---|
| 핵심 가치 | 개인정보. 기본은 모든 것이 기기 안에서 돌고, 계정이 필요 없고, "수집하는 데이터 없음" |
| 모델 | GGUF·MLX·ExecuTorch·Core ML·Apple Foundation Models 형식의 오픈 모델을 앱 안에서 내려받아 실행. 내려받기 전에 **기기 메모리에 맞는지**와 컨텍스트 안내를 보여 줌 |
| 자료 | PDF·EPUB·교과서·노트를 가져와 기기 안에서 색인하고(RAG), 질문하면 관련 구절을 찾아 근거로 답함 |
| 공부 | 자료로 요약·노트·플래시카드(간격 반복)·퀴즈·팟캐스트·보고서를 만들어 "Saved" 보관함에 모음 |
| 선택 기능 | 웹 검색·딥 리서치, 원격 제공자(OpenAI 호환·OpenRouter·Ollama·LM Studio)는 **사용자가 켤 때만** 씀 |
| 기기 연결 | Mac이 모델을 돌리고 iPhone이 빌려 쓰는 Constellation/Relay, 로컬 API 서버 |

## 3. 구현 메모

### 이 기기 모델
- 엔진: `@huggingface/transformers@4.3.2` (워커 안에서 `AutoTokenizer` + `AutoModelForCausalLM.generate`, `TextStreamer`로 토큰을 보내고 `InterruptableStoppingCriteria`로 멈춤). 요청은 큐로 하나씩.
- 시험 결과(헤드리스 Chromium, WebGPU 없음 = CPU):
  - **Qwen3 0.6B `q8`**: 618MB를 약 30초에 받고, "한국의 수도는?" → 생각 53초 뒤 "서울" 정상 답변.
  - **LFM2·Gemma 3 양자화본**(`q4`, `q8`): CPU(WASM)에 없는 `GatherBlockQuantized` 연산을 써서 세션을 못 만듦. 그래서 이 모델들은 **WebGPU에서만** 고를 수 있게 하고 "WebGPU 필요"로 표시. (transformers.js 3.7.2에서는 같은 문제가 숫자 오류 코드로만 보여서 4.3.2로 올림.)
  - WebGPU 경로는 이 환경에 GPU가 없어 직접 돌려 보지 못함 — 표준 transformers.js 사용법 그대로임.
- 작은 모델용 메시지 정리: 이미지 → 안내 문장, 같은 역할 연속은 합침, 시작은 user, 최근 약 9,000자만, 시스템 프롬프트 5,000자 상한(Gemma 템플릿의 역할 교대 규칙 대응).

### 내 자료 검색
- 저장: IndexedDB `lfm-lib`(`docs`, `saved`). 채팅 기록은 계속 localStorage.
- 색인: 문서마다 조각별 단어 빈도를 메모리에서 처음 검색할 때 만듦(BM25, k1=1.2, b=0.75). 한국어 형태소 분석 대신 두 글자 묶음을 써서 조사·어미에 덜 흔들림. "알려 줘·뭐야" 같은 질문 말투는 불용어.
- 보낼 양: 최대 약 6,200자. 웹 검색 결과와 함께 쓸 수 있고 번호 체계가 달라서(`[1]` 웹 / `[자료1]` 문서) 섞이지 않음.

### 분기와 버전
- 사용자 메시지에 `alts:[{text,img,tail}]`, `alt` — 보이는 분기의 뒤 대화는 `c.msgs`에만 두고(`tail:null`), 숨은 분기만 `tail`에 보관해 중복 저장을 피함. 분기 안에 또 분기가 있어도 메시지 객체째 보관되므로 그대로 살아남음.
- 답변에 `vers:[스냅숏]`, `vi`. 메모리 압축으로 정리된 메시지(`memStart` 이전)는 고칠 수 없게 함.

### 시험
- 가짜 OpenAI 호환 서버로 14가지 흐름을 Playwright로 확인: 기본 대화, 재생성 버전, 질문 고치기·분기 이동, 모델 비교·선택, 긴 TXT 검색(정답 절만 골라 보냄), PDF·MD 가져오기, 기억 저장과 시스템 프롬프트 반영, 플래시카드·복습·퀴즈 채점·요약→Canvas, 보관함, 프로젝트 지침·자료 반영, 오프그리드 차단, 이 기기 모델 창, 블루프린트(키 미포함), 외부 엔드포인트(오프그리드에서 localhost 허용), 휴대폰 폭(가로 스크롤 없음). 콘솔 오류 없음.
